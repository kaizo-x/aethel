# Aethel — AI Event Planning Atelier 🏛️

> **Google PromptWars Submission** | An editorial, GenAI-powered event orchestration platform built with Next.js, Tailwind CSS, and Gemini GenAI.

Aethel moves away from generic, chat-wrapper AI interfaces to offer an architectural event planning dossier for weddings, milestone celebrations, and civic drives.

---

## Key Features

- 🎨 **Editorial Design System**: Crafted with a bespoke Kinfolk-inspired aesthetic using `Playfair Display` serif headings and `Plus Jakarta Sans` typography.
- ⚖️ **Dynamic Budget Rebalancing Engine**: Real-time category allocation with lockable financial constraints, itemized line items, and over-budget safeguards.
- ⏳ **Reverse-Engineered Timelines**: Chronological milestone tracking from *T-6 Months* down to an interactive hour-by-hour *Day-Of Schedule*.
- ✉️ **Artisan Vendor Directory & Smart Inquiry Drawer**: AI-powered outreach email generation with 1-click tone adaptation (*Curatorial*, *Negotiation*, *Contract Deadline*).
- 🧠 **Context-Aware AI Co-Pilot**: Actionable AI prompt cards that modify live state directly (rebalancing budgets, injecting emergency contingency milestones).
- 📜 **Export & Print Dossier**: Full client-side `localStorage` persistence, JSON data export, and architectural print preview (`window.print()`).

---

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS, Lucide Icons
- **State Management**: React State + Web Storage API (`localStorage`)
- **Typography**: Google Fonts (`Playfair Display`, `Plus Jakarta Sans`)
